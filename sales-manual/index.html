前後の流れを確認する

まずは全体像をつかみましょう

  1. 告知

    個別相談を知ってもらう方法は3つ

    最初のお客様は、どこから出会う？

    ①リアル人脈すでに信頼がある→ 最初の1人におすすめ
    ②所属コミュニティ普段から関係をつくる→ 関係性の中から相談へ
    ③SNS問題提起→未来提示→CTA→ 発信と対話の先に個別相談

    起業初期は ①→②→③ がおすすめ
    フォロワー0人でも、
    最初のお客様はつくれる

    • ① リアル人脈に声をかける軽い営業DMではなく「実はこんな挑戦を始めようと思っていて、まずあなたに話を聞いてほしい」と、なぜこの仕事を始めるのか・なぜあなたに連絡したのか・率直な意見を聞きたいことを、自分の言葉で誠実に
    • ② 所属コミュニティに食い込む地域やオンラインのコミュニティで、普段から関係をつくる。チラシやDMを置かせてもらうのも◎
    • ③ 自分のSNSで告知する基本は「問題提起 → 未来提示 → CTA」。ただし、継続発信やフォロワーさんとの対話がほぼない状態で、突然「個別相談募集」だけ出しても来にくいです

  2. お申込みフォーム＆事前アンケート

    初心者さんには Googleフォーム がおすすめ

    • 無料／写真などで世界観もつくれる
    • 回答をスプレッドシートで管理できる
    • 事前ヒアリングを兼ねられる

    記述式だらけにせず、ラジオボタンや選択式が中心。本当に聞きたいところだけ記述式に。記入が負担にならず、当日が楽しみになるフォームに。
    有料商品のご案内があること・キャンセルについて・お子さま連れの可否など、必要事項も明記しておきましょう

    参考フォーム（Googleフォーム）

    ※そのままコピーするのではなく、自分の商品・サービスに置き換えてモデリングしてくださいね

  3. 個別相談に必要なものを準備

    ご提案書／決済フォーム・決済リンク／契約書／Zoom／印象ブランディング／通し練習

    ご成約は、準備9割

    → 詳しいチェックは 03 へ

    当日の2時間だけで売るのではなく、事前から価値と信頼を届ける。必要に応じて、事前に見てほしいPDF・動画・リールも添えて

  5. 個別相談 当日

    電波・PC充電・Zoom・画面共有・ご提案書・事前アンケート・自分用メモ・通知OFF・見られたくない画面を閉じる……を余裕をもって確認して、スタンバイ

    → 進め方は 04 へ

  6. 相談後 3時間以内

    原則、終了後3時間以内にサンキューメール／LINE。ご縁と時間への感謝、印象に残ったこと、そして本プログラムへの意思確認（原則、翌日までのお返事）まで

    「ありがとうございました」で終わらせないのがポイント → 06 へ

  7. お申込み・契約・決済

    1. 契約書
    2. 決済
    3. 入金確認
    4. ウェルカム案内

    → 注意点は 07 契約時の注意点 へ

    初回日程／LINE・Slackなどの連絡環境／事前課題／今後の流れ／必要な資料づくり

シンクロセールス
7つの極意

感謝されて自然と売れる土台

ご成約率がすべて

一般的な
個人起業家の
ご成約率20%
ここらぼ式
シンクロセールスの
ご成約率50%+

なぜ「率」が大事なの？

10万円の商品を、同じ10人に提案すると……

成約率10%1人売上 10万円
成約率50%5人売上 50万円

売上を5倍にする方法は、集客を5倍にすることだけじゃない
量だけを増やす前に、率を上げる

もうひとつの見方

  • 2,000円のタロット鑑定で20万円 → 100件必要
  • 20万円の継続プログラムを1人に届ける → 1件で20万円

安い商品が悪いわけでも、高額なら何でもいいわけでもありません。自分の時間・エネルギー＋お客さまの変化の深さまで含めて、商品を設計しましょう

成約率を上げる土台は4つ

  1. コーチング・対話の基本11月の次元上昇Zoomで扱う予定です
  2. ダイレクトレスポンスマーケティング
  3. 売れるご提案書
  4. 契約・決済など、安心して買える準備

「シンクロセールス」とは

自分が売るのではなく、相手の気持ちの流れ（感情曲線）にぴったり寄りそうセールス。シンクロナイズドスイミングのように呼吸を合わせて、相手の最大の理解者になることです

  1. 一本道全体でクロージング

    個別相談2〜3時間の「点」で売るのではありません。発信 → LINE → 制作物 → やり取り → 個別相談、そのすべてを通して「この人なら大丈夫」という信頼貯金が貯まっていきます

    個別相談で一本釣りするのではなく
    信頼貯金をコツコツ貯めて
    満期になった人がご成約する

    0→1フェーズ目安：月商50万円を安定させるまで
    1. リアル人脈・SNS
    2. 公式LINE
    3. 軽い特典
    4. お申込みフォーム
    5. 個別相談
    6. ご成約

    発信はトークリール中心。リアル人脈も強く活用

    0→1以降目安：月商50〜300万円を安定させたい
    1. SNS・広告・リアル人脈
    2. オプトインLP
    3. 公式LINE
    4. ステップ配信（UTAGE・エルメなど）
    5. 動画講座など
    6. お申込みフォーム
    7. 個別相談
    8. ご成約

    売上額だけでなく、魂商品に最低10人程度は実際にお客さまを通していることもひとつの目安

    講師経験が少ないうちに複雑な導線を先につくると、何を伝えるべきかがまだ見えていなくて大変です。まず、届ける経験を積む

  2. 相手の人生を幸せにするまでが集客

    漁業型（取って終わり）ではなく、農業型で

    1. 知る
    2. 関係をつくる
    3. 信頼を育てる
    4. 届ける

  3. セールス＝プロポーズ

    「売る」とは、相手に愛のご提案をすること

    あなたと、こんな未来を一緒につくりたい

  4. とことん相手目線

    自分の頭だけで考えない。相手の脳で考える

    • 今この話を聞いたら、どう感じる？
    • 今これを伝えて大丈夫？
    • 何が不安？ 何がまだ見えていない？
    • 本当は何を知りたい？

    自分が伝えたい量より、相手の感情曲線を見る

  5. ダイレクトレスポンスマーケティング

    一方的に進めず、相手のYESを取りながら次へ進む。知りたいと言った人にだけ次のお話をするので、相手が不快な思いをしません。そして最後が金額

    売り込まないセールス新常識

  6. お金の話を正々堂々とする

    金額・支払方法・分割の総額・キャンセル条件を、濁さず誠実に

  7. 反論処理ノートをつくる

    答えに困った質問・不安・迷いを毎回記録して、次回に活かす

シンクロセールスは
喋る技術ではなく
相手の心を見る力

個別相談当日の進め方

全体の目安60〜90分

  1. 5分程度

    ① オープニング

    アイスブレイクで心を開いてもらう

    • アイスブレイクで、緊張をほどく
    • 全体像（森）を見せる：今日かかる時間、どんなことをするか
    • 前半は個別相談。後半に有料のご案内があるけれど、聞きたい場合だけお話しするので安心して選んでね、と伝える
    • 録画する場合は、必ず許可をとる
  2. 15分程度

    ② ヒアリング

    事前アンケートをもとに、ここまでを明確に

    • 今の現在地
    • 本人が自覚している課題
    • どこへ行きたいのか

    ここは「無料お悩み相談」ではありません。悩みを解決しすぎない、大量のアドバイスをしない

  3. ③ 前半：セールスパート

    本人がまだ見えていない「行き先」を一緒に言語化する

    ご提案書に合わせて

    1. 問題提起
    2. 自分のストーリー
    3. 未来提示・行き先
    4. 解決への道

    一方的に話さず、相手の顔・表情・反応・感情曲線を見ながら。感情曲線が止まった、閉じた、不安そう、思考停止した……その違和感を察するのが、シンクロセールスのいちばん大事なところ

  4. ④ YESを取る

    前半が終わったら、一度区切る

    ここから先は、私が実際に提供しているプログラムの具体的な内容・金額のお話になります。ここまで聞いて、もっと詳しく聞いてみたいと思いますか？

    • YES → 後半へ
    • NO → 気持ちよく終了。相手を責めず、前半のどこでシンクロできなかったかを後で振り返る（09）

  5. ⑤ 後半：ガイダンス・クロージングパート

    プログラム・講座・セッションを改めてご案内

    • カリキュラムの細部を長々と説明しない
    • 軸は「なぜこれが必要なのか」「この人がどんな行き先へ行くためなのか」
    • そのうえで、金額を正々堂々と伝える
    安心と希望のクロージング

  6. ⑥ 最終確認

    押し込まない、プッシュしない

    • 不安はないか
    • 聞いておきたいことはないか
    • 本人はどう感じているか
    • 自分の想いも誠実に伝える

    理想は「これ、私のための商品ですね」「やりたいです」が自然に出る状態
    即決 → 次の手続きへ（06）／保留 → 06のサンキューメールへ

絶対NG：個人情報の取り扱い
当日の内容、お客さまとのZoomの画面写真、個人が特定できる情報は、本人の許可なくストーリーズやSNSに出さない。「セッションしました」と気軽に載せてしまう方が多いので要注意です

05

クロージング時の
不安への対処法

反論を言い負かすのではなく、不安の正体を一緒に見る

① 受け止める
「不安になるのは自然です」「私もそうでした」
② 不安の正体を一緒に見る
お金？ 時間？ 自信？ ご家族？ 何が引っかかっているのかを、責めずに聞く
③ 安心材料を渡す
「お支払い方法を選べます」「最後まで伴走します」
④ 未来をもう一度一緒に見る
この選択の先にある景色を、一緒に思い描く
「夫（家族）に相談したい」

家族を大切にする気持ちを受け止め、ご本人のお気持ちを確認。やりたい場合は、家族に伝えるポイント（内容・期間・金額・得られる変化）を一緒に整理して、お返事の目安を決める

「お金が不安…」

まずは気持ちを受け止め、「金額そのもの」と「払い方」のどちらが気になっているかを聞く。払い方なら、分割・クレジットカードと総額を説明

「自分にできるか不安…」

不安は本気の証拠と受け止め、サポート体制と、同じような状況からスタートした方の例を伝える。「絶対できます」と成果を約束する言い方はしない

「時間がなくて…」

1日にとれる時間を聞き、録画やスマホでできることなど、現実的な進め方を一緒に考える

「一度自分でやってみたい」

その気持ちを尊重したうえで、自分でやる場合とサポートを受ける場合で、行き先までの道のりや時間がどう違いそうかを一緒に見てみる

「少し考えたいです」

どのあたりを考えたいかを聞き、今ここで解消できることには答える。それでも考えたい場合は、お返事の目安を一緒に決める

NOが出たときほど、相手の問題にする前に振り返る

個別相談まで来てくださった方は、何かしらの興味や可能性を感じて来ています

導線／前半の伝え方／行き先／信頼／タイミング／ペルソナとのズレ

もちろん、そもそもペルソナではない、タイミングが違う、今は買わない方がいい、というケースもあります。全員がご成約するのが正解、ではありません

これだけは守る
  • 借金（カードローン・消費者金融など）をすすめない
  • 無理な即決を迫らない
  • 長時間引き止めない

契約時の注意点

全部完璧にしてから…じゃなくて大丈夫。ここだけ押さえよう

いちばん大事

これだけは守る

  • 誇大表現をしない：「誰でも絶対月収100万」「必ず稼げる」など
  • 成果を保証しない
  • お客さまの声や写真は、本人の許可をとる
  • 借金をすすめない・即決を迫らない・長時間引き止めない
  • 個人情報を丁寧に扱う

契約書

ここらぼでは、金額にかかわらず、契約内容を双方で確認できる形に残すことを強くおすすめします。特に継続講座・高額商品は契約書を用意しましょう

基本の項目

商品商品・サービス名／提供内容／期間
お金金額／支払方法
解約キャンセル・中途解約
守る守秘義務／著作権／個人情報
その他免責／双方で確認すべき事項

クラウドサインなどの電子契約を使うと、管理がしやすくなります。雛形を自分のサービスに合わせて書きかえ（AIも活用）、心配な方は一度だけ専門家にチェックしてもらうと安心です

知っておく

特定商取引法に基づく表記

オンラインの販売ページなどから申込みを受ける場合など、必要に応じて「特定商取引法に基づく表記」を準備します

価格／支払方法／提供時期／解約・返金条件／事業者情報 などを、わかりやすく表示

具体的な適用の判断は、販売方法や契約形態によって異なります。不安な場合は、消費者庁や専門家などで確認しましょう

知っておく

解約・返金・キャンセル

解約・返金・キャンセル条件は、販売方法や契約形態によって扱いが異なります。自分の商品に合った条件を決め、申込前にわかりやすく提示しましょう

売上の計算方法

受け取るお金は、すべてこの計算

魂商品の価格 × ご成約数 ＝ 月商

例）受講料20万円（3ヶ月）× 月3人 ＝ 月商60万円
同じリズムで1年続けると ＝ 年商720万円

自分の数字で計算してみる

月商60万円
年商720万円
同時に支えるお客さま9人

ただし！自転車操業にならないために

月3人を受け入れると、3ヶ月後には9人を同時にサポートしながら、新しいセールスと集客・毎日の発信も続けることになります

だからこそ欠かせないのが、せるこ・8 サポート内容（フェーズ設計）。何人まで・どこまで・どの方法でサポートするかを先に決め、グループと個別で伝えることを分けて仕組み化しておきましょう
